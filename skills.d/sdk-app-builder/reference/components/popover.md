# Popover

Focus-within content panel. Appears when trigger is focused.

```html
<div class="popover">
  <button class="btn btn-sm" tabindex="0">More info</button>
  <div class="popover-content" style="left:0; transform:none;">
    <div class="text-bold mb-xs">About this feature</div>
    <p class="text-sm text-dim m-0">This popover appears on focus.</p>
    <button class="btn btn-sm btn-primary" style="margin-top:8px;">Got it</button>
  </div>
</div>
```
