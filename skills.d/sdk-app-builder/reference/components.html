Pattern rules — what NOT to do
WRONG — common LLM mistakes
  • Solid background: var(--accent) on tags — use .tag.tag-accent (translucent 15%)
  • Custom border-left on cards — cards have no borders, use .card as-is
  • Inline text-transform: uppercase; font-size: 11px — use .text-xs.text-bold
  • Custom italic class for hook text — use style="font-style:italic" on .text-sm.text-dim
  • Hardcoded colors like #ff6b35 or rgba(...) — always use CSS variables
  • Custom border-left: 3px solid var(--danger) on cards — use .alert.alert-danger instead

What is ALF?
ALF is a personal AI assistant that runs on your own infrastructure. It manages apps, tools, and conversations.
How do I install apps?

Use the marketplace in the Control Center to browse and install apps. Apps run in sandboxed iframes with their own storage.

Each app gets its own isolated directory and key-value storage. Updates preserve your data automatically.

Can I build my own apps?
Yes! Use the SDK App Builder skill. Apps are vanilla HTML/CSS/JS using the AlfSDK and alf-ui.css design system.
